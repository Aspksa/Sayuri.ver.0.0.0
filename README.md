# Sayuri Yukishiro

**Релиз:** v0.1.0 · **Ядро:** v0.1.0 · **В разработке:** v0.2.0

Переносимая персональная платформа. Работает с любого носителя: внутреннего диска, внешнего диска или флешки — без установки и без настройки путей.

## Запуск

Запустите **«Sayuri Yukishiro.bat»**.

Дальше всё происходит само:

1. определяется корень проекта от расположения файла — без привязки к букве диска;
2. ищется Python: портативный в `runtime\python`, затем `.venv`, затем системный;
3. если носитель защищён от записи, данные переносятся в профиль пользователя;
4. выполняется диагностика готовности;
5. поднимается ядро, занимается свободный порт;
6. **сайт открывается в браузере автоматически.**

Повторный запуск `.bat` не создаёт второй экземпляр — он открывает уже работающий сайт.

Адрес по умолчанию: `http://127.0.0.1:8765`. Если порт занят, берётся свободный, и фактический адрес записывается в `data/runtime/endpoint.json`.

## Ядро v0.1.0

- **Переносимость** — никакой привязки к букве диска; тесты это проверяют.
- **Политика носителя** — WAL на локальном диске, DELETE с `synchronous=FULL` на съёмных, сетевых и синхронизируемых путях.
- **База с миграциями** — объявленный список миграций; база новее сборки отклоняется, а не портится.
- **Жизненный цикл служб** — запуск в порядке регистрации, остановка в обратном, откат уже запущенных служб при сбое.
- **Конфигурация** — значения по умолчанию, `config/system.json`, переменные окружения.
- **Журнал** — структурированный, с ротацией файлов.
- **Шина событий** — сбой одного обработчика не отменяет доставку остальным.
- **Фоновые задачи** — ограниченная история, освобождение futures, фиксация прерванных задач после перезапуска.
- **Контрольные точки** — обязательный `next_action`, восстановление без автоматического повторения действий.
- **CoreAPI** — единственный интерфейс ядра для будущих модулей.
- **Диагностика** — Python, носитель, хранилище, интерфейс, база, ядро, браузер, экземпляр, порт, Git.

## Командная строка

```
python -m sayuri_yukishiro.main --preflight      # только диагностика
python -m sayuri_yukishiro.main --serve          # ядро и сайт
python -m sayuri_yukishiro.main --serve --no-browser
python -m sayuri_yukishiro.main --endpoint       # адрес запущенного экземпляра
```

Лаунчер: `powershell -File scripts\launcher.ps1 [-PreflightOnly] [-SkipPreflight] [-NoBrowser] [-Port 9000]`

## Локальный API

Только петлевой интерфейс.

| Эндпоинт | Содержимое |
|---|---|
| `GET /api/health` | краткое состояние |
| `GET /api/core` | состояние ядра и служб |
| `GET /api/core/jobs` | фоновые задачи |
| `GET /api/core/recovery` | незавершённые задачи с `next_action` |
| `GET /api/core/events` | последние события |
| `GET /api/core/config` | действующая конфигурация |
| `GET /api/modules` | реестр модулей |
| `GET /api/system` | полная сводка: носитель, схема, адрес, запуски |
| `POST /api/shutdown` | мягкая остановка, требует токен |

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `SAYURI_PORT` | порт локального сервера |
| `SAYURI_AUTO_PORT` | брать свободный порт, если штатный занят |
| `SAYURI_OPEN_BROWSER` | открывать сайт автоматически |
| `SAYURI_DATA_DIR` | каталог runtime-данных |
| `SAYURI_SQLITE_JOURNAL_MODE` | `WAL` или `DELETE` |
| `SAYURI_LOG_LEVEL` | уровень журнала |
| `SAYURI_CORE_MAX_WORKERS` | число фоновых потоков |
| `SAYURI_JOB_HISTORY_LIMIT` | предел истории задач в памяти |
| `SAYURI_RECOVERY_ENABLED` | включить восстановление |

## Требования

Python 3.11+. Для запуска через `.bat` — Windows PowerShell. Ядро и тесты работают также на Linux и macOS.

